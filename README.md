# Early Prediction of Information Cascades in Social Networks Using Community Structure, Link Prediction and Network Centrality

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository contains the complete, reproducible Social Network Analysis (SNA) and Machine Learning research pipeline for predicting the eventual final size of information cascades using early temporal dynamics, network centrality metrics, community structure, and structural link prediction.

---

## 📌 Research Overview & Core Question

**Core Research Question:**  
*"Can network centrality, community structure, link-prediction features and early temporal information be used to predict the eventual growth and final size of an information cascade in a web media network?"*

**Primary Target Variable:**  
`target_final_size` = Total number of **unique participating websites/nodes** reached by the end of the cascade ($|V_{cascade}|$).

**Key Scientific Distinction:**  
Edges in this dataset represent **inferred propagation relationships** generated by NETINF optimization, rather than confirmed causal hyperlinks or ground-truth mentions.

---

## 📊 Dataset Specification

- **Dataset:** MemeTracker / NETINF Information Cascade Dataset (`InfoNet5000Q1000NEXP.txt`).
- **Nodes ($|V|$):** 960 unique web media domain hostnames and blogs (733 unique source originators, 953 unique destinations).
- **Edges ($|E|$):** 5,000 directed weighted propagation edges.
- **Cascades ($N$):** 1,000 extracted cascade diffusion trajectories.

## ⚡ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/user/SNM-Information-Cascade-Prediction.git
   cd SNM-Information-Cascade-Prediction
   ```

2. **Create a virtual environment and install requirements:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

## 🔬 Reproducibility & Scientific Rigor

- **Zero Temporal Leakage:** Feature variables are strictly restricted to events $\le p$. Partitioning is executed at the **CASCADE level** (70% train, 15% val, 15% test).
- **Deterministic Execution:** Random seeds (`seed=42`) are fixed across all train/test splits, Link Prediction candidate sampling, and ensemble models.
- **Empirical Validation:** 0 missing values across all serialized CSV outputs.
